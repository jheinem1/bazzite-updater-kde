# Upstream and licenses

This independent, desktop-focused fork preserves the history and per-file notices of [rfrench3/bazzite-updater](https://github.com/rfrench3/bazzite-updater). The initial source baseline is `172c28adf55bb71bab0592c3b72e7c555469f6ee` (upstream version 1.2.1).

The original Bazzite Updater was created by Robert French. Additional contributors are credited in the source and Git history. Application code is generally GPL-2.0-or-later; individual files retain their stated alternatives, including KDE-accepted GPL terms. Build files and assets have their own notices, including BSD and CC0. Preserve those notices and all files in LICENSES when redistributing.

Controller input uses [rfrench3/controllable](https://github.com/rfrench3/controllable), pinned as a Git submodule. Its own source notices and licenses apply. The fork does not modify that dependency.

The Bazzite artwork and distributor logo retain upstream attribution. Sources are documented in README-upstream.md. This project does not imply endorsement by Bazzite, Universal Blue, KDE, or the upstream maintainer.

Closing contributions is a repository policy only, not a restriction on license rights.
